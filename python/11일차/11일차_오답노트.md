## 2. 문제별 오답 분석 및 약점 포인트

### 1) Python 11일차 1번 (타겟 넘버)
- **변수명 오타**: `answre = 0` 오타 작성으로 인한 `NameError` 발생.
  - -> 변수 선언 시 정확한 스펠링 확인 필수.
- **종료 조건의 리스트 길이 접근 오류**: `if i == len(stack[numbers]):` 처럼 엉뚱한 인덱스로 접근.
  - -> 전체 숫자의 개수인 `len(numbers)`와 현재 인덱스 `i`를 비교하여 탐색 종료 시점 결정.
- **스택 튜플 인덱스 전진 방향 오답**: 빼기 연산 처리 시 `stack.append((i-1, j-num))`으로 작성하여 이전 인덱스로 되돌아가는 오류 발생.
  - -> `+` 연산을 하든 `-` 연산을 하든 다음 숫자로 넘어가야 하므로 인덱스는 동일하게 `i + 1` 전진 적용.
- **탐색 상태 지속성 이해**: `j == target`인 조건을 만족해도 `while stack:` 조건에 의해 스택에 남은 다른 갈림길 경로들을 모두 탐색하여 누적 계산함을 파악.

### 2) Python 11일차 2번 (더 맵게)
- **정렬 방식 선택과 시간 복잡도**: 매 갱신마다 `scoville.sort()`를 실행하면 $O(N^2 \log N)$으로 시간 초과 발생.
  - -> 파이썬의 최소 힙 `heapq.heapify(scoville)`를 사용하여 $O(N \log N)$으로 최솟값을 유지하도록 구현.
- **남은 원소 예외 처리 누락**: 계속 섞다가 남은 음식이 1개인데 여전히 `K` 미만일 경우 `heappop()`을 2번 연속 호출하여 `IndexError` 발생.
  - -> `while`문 내부에서 `if len(scoville) < 2: return -1` 예외 처리 필수 추가.

### 3) Python 11일차 3번 (단속카메라)
- **람다(lambda) 정렬 조건 적용**: 진출 지점 기준 정렬을 위해 `sorted(routes, key=lambda x: x[1])` 적용.
- **`sort()` 메서드 반환값 주의**: 과거 9일차 3번 문제처럼 `routes = routes.sort(...)`로 대입하면 `None`이 되는 점 유의 (`routes.sort(...)` 단독 사용 또는 `sorted()` 활용).
- **카메라 초기 위치 및 루프 조건**: 첫 카메라는 `for`문 바깥에서 `camera = routes[0][1]`, `count = 1`로 딱 1번 초기화하고, 두 번째 차량부터 `for route in routes[1:]:` 로 순회.
- **진출 지점 정렬의 그리디 본질**: 가장 먼저 나가는 차량의 진출 지점에 카메라를 대어야 이전에 들어온 겹친 다른 차량까지 한 번에 최대 단속 가능.

### 4) Python 11일차 4번 (게임 맵 최단거리)
- **매개변수 덮어쓰기 오타**: `maps = [(0,0)]` 으로 재할당하여 매개변수 2차원 맵 데이터 전체를 원소 1개짜리 리스트로 상쇄시킴.
  - -> `maps[0][0] = 0` (출발 지점 방문 처리)과 변수 재할당 구분.
- **들여쓰기(Indentation) 오류**: `if 0 <= ny < len(maps)...` 유효성 검사 블록을 `for i in range(4):` 문 바깥에 작성하여 4번째 방향 하나만 검사함.
  - -> `if`문 블록 전체를 `for`문 내부로 들여쓰기하여 상/하/좌/우 4방향을 각각 검사하도록 수정.
- **2차원 배열 인덱싱 구조**: `len(maps)`는 세로(행) 길이, `len(maps[0])`은 가로(열) 길이이며, `maps[y][x]` 형태로 세로를 앞 인덱스에 넣어야 함.

## 3. 핵심 배운 점 및 요약 패턴

1. **DFS/BFS (스택/큐)**: `stack.pop()` 또는 `queue.popleft()`로 꺼낸 (인덱스/좌표, 상태)가 '현재 위치'가 되므로 별도 현재위치 변수가 필요하지 않음.
2. **최소 힙 (`heapq`)**: 매번 최솟값을 추출하고 갱신할 때는 `heapify`, `heappop`, `heappush` 삼총사를 활용하고 남은 개수 예외 처리(`len < 2`)를 챙길 것.
3. **그리디 (`key=lambda x: x[1]`)**: 구간/스케줄링 문제에서 가장 빠르게 끝나는 지점(진출 지점)을 기준으로 정렬하여 탐욕 선택 진행.
