## 2. 실수 및 약점 분석 노트

### [K번째수]
- **`list.append()` 인자 개수 오류**: `append(a, b)`처럼 2개 이상의 인자를 넘기면 `TypeError: list.append() takes exactly one argument (2 given)`가 발생함. 반드시 단일 값만 넘길 것 (`append(b)`).
- **1-based vs 0-based 인덱스 차이**: 문제의 $i$번째는 파이썬 0-index 기준 $i-1$ 인덱스이며, $k$번째 원소는 $k-1$ 인덱스임.

### [가장 큰 수]
- **자릿수가 다른 문자열 비교 정렬 문제**: `'3'`과 `'30'`을 내림차순 정렬하면 `'30'`, `'3'` 순이 되어 `"303"`이 되지만, 실제 최댓값은 `"330"`임.
  - **해결 패턴**: 문자열을 3회 반복하여 비교하는 `key=lambda x: x*3` 패턴 적용 (`'333'` > `'303030'`).
- **`list.sort()` 반환값 유의**: `list.sort()`는 제자리 정렬로 `None`을 반환하므로 `"".join(list.sort())` 형태로 직접 사용 불가. `sorted()`를 쓰거나 정렬 후 `join`을 따로 수행할 것.
