## 2. 실수 및 약점 분석 노트

### [주문량이 많은 아이스크림들 조회하기]
- **문자열 컬럼 집계 오류**: `SUM(FLAVOR)`처럼 문자열 컬럼에 `SUM()`을 적용하면 잘못된 결과가 발생함. 집계 대상은 주문량 컬럼인 `TOTAL_ORDER`(`A.TOTAL_ORDER + B.TOTAL_ORDER`)이어야 함.
- **1:N 관계 조인 및 `GROUP BY` 누락**: `JULY` 테이블에는 동일한 맛(`FLAVOR`)에 대해 여러 출하 데이터가 존재하므로, 조인 후 맛별로 합산하기 위해서 반드시 `GROUP BY FLAVOR`가 필요함.
- **정렬 방향 오설정**: "주문량이 많은 순서"는 오름차순(`ASC`)이 아닌 **내림차순(`DESC`)** 정렬(`ORDER BY SUM(...) DESC`)이어야 함.
- **서브쿼리 사전 집계 권장 패턴**: `JULY` 테이블에서 맛별 총 주문량을 먼저 `GROUP BY FLAVOR`로 집계한 뒤 `FIRST_HALF`와 `JOIN`하여 주문량을 합산하거나, `UNION ALL` 후 `GROUP BY` 패턴을 적용하는 것이 안전함.

### [카테고리 별 도서 판매량 집계하기]
- **서브쿼리 SELECT 키 컬럼 누락**: `SELECT SUM(SALES)` 서브쿼리 내에 `BOOK_ID` 컬럼을 SELECT 항목에 포함하지 않아 외부 쿼리의 `ON A.BOOK_ID = B.BOOK_ID` 조인이 불가능함.
- **구문 키워드 오타**: `ON = A.BOOK_ID` 처럼 중복 기호 오타 및 `SAELS_DATE` 오타 주의.
- **날짜 범위 조건 지정 유의**: `SALES_DATE` 2022년 1월 추출 시 `SAELS_DATE <= '2022-02'` 사용 시 유실 위험 발생. `SALES_DATE LIKE '2022-01%'` 또는 `DATE_FORMAT(SALES_DATE, '%Y-%m') = '2022-01'` 활용.
- **최종 카테고리별 그룹화 누락**: 단순 책 ID별 합산 후 조인만 수행 시 카테고리 단위로 최종 합산되지 않음. `BOOK`과 `BOOK_SALES` 조인 후 `GROUP BY A.CATEGORY`를 수행하는 직관적 쿼리 권장.

### [대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기]
- **메인 쿼리 HAVING절 오용 오류**: 메인 쿼리에 `HAVING COUNT(*) >= 5`를 적으면 '월별 대여 횟수'가 5회 이상인 월만 남게 됨. 전체 기간(8월~10월) 합산 5회 이상 대상차량을 거르기 위해 서브쿼리 `HAVING COUNT(*) >= 5`를 필수 적용해야 함.
- **`BETWEEN ... AND` 문법 오용 및 테이블명 오타**: `DATE_FORMAT(...) = "2022-08" between ...` 처럼 `=` 기호와 `BETWEEN`을 오용하는 문법 오류 및 `CAR_LENTAL...` (RENTAL이 맞음) 오타 주의.
- **ORDER BY 구문 오타**: `ORDER BY MONTH ASC. CAR_ID DESC` 마침표(`.`) 오타 주의 $\rightarrow$ 콤마(`,`) 구분자 사용.
